Full-stack web app

Campus Lost & Found Board

A board where students report things they lost or found on campus. Each post has a photo, a category and a short description, and anyone can search the board to find a match.

  • Students post lost or found items with photos, then search the board by keyword, category and type, 12 posts per page.
  • Session-based login with bcrypt password hashing. Post ownership is checked on the server and again in SQL, so users can edit or delete only their own posts.
  • Three-table MySQL schema (users, categories, posts) with foreign keys, cascade rules and indexes, plus seed data and setup scripts.

    How the data is organized

    The MySQL schema behind the board.

    users

    • id PK
    • name VARCHAR
    • email UNIQUE
    • password_hash bcrypt
    • created_at DATETIME

    categories

    • id PK
    • name UNIQUE

    posts

    • id PK
    • user_id FK → users
    • category_id FK → categories
    • type lost | found
    • title, description TEXT
    • location, photo VARCHAR
    • created_at INDEX

    Deleting a user removes their posts through a cascade rule. Indexes on type, category and date keep the search and paging queries fast as the board grows.

    Computer vision · Personal project

    Plant Disease Detection

    A model that looks at a photo of a plant leaf and says which of 10 classes it belongs to, covering healthy and diseased leaves from apple, cherry, peach, pepper, potato, rice and tomato plants.

    • Built on ResNet50 with transfer learning. I trained a new classification head first, then unfroze the last 50 layers and fine-tuned at a lower learning rate.
    • Data pipeline for 10,000 images: 70/15/15 train, validation and test split, resizing, normalization, and augmentation on the training set only.
    • Checked the results with a per-class report, a confusion matrix and Grad-CAM heatmaps that show which part of the leaf the model looked at.
    • Wrote a prediction function that takes a new image file and returns the disease name and a confidence score.

    Computer vision · Personal project

    ASL Sign Language Recognition

    A model that reads American Sign Language hand signs from images and returns the letter. It covers A to Z plus the signs for space, delete and "nothing".

    • Used MobileNetV2 because it's small and fast enough for live video: 2.6 million parameters on 96×96 images.
    • Trained in two phases on 87,000 images: first only the new classification layers, then fine-tuning the top 15 layers, with early stopping and a learning rate that drops when progress stalls.
    • Measured precision, recall and F1 for every letter and used a confusion matrix to find the hard pairs, such as X, Y and Z.
    • Includes a webcam script with OpenCV that predicts the sign inside an on-screen box as you hold it up.
